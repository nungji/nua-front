# 마트 상품 아이콘

마트 60단어의 상품 아이콘. 파일 이름은 단어 그대로다(예: `우유.png`).

출처: Microsoft Fluent Emoji 3D (https://github.com/microsoft/fluentui-emoji), MIT 라이선스.
딱 맞는 이모지가 없는 단어는 비슷한 이모지로 대신했다.

| 요거트 | Custard | 김치 | Jar |
| 치마 | Dress | 세제 | Lotion bottle |
| 베개 | Bed | 기저귀 | Baby bottle |
| 치약 | Tooth | 수건 | Bathtub |
| 다리미 | Electric plug | 드라이기 | Dashing away |
| 리모컨 | Mobile phone | 선풍기 | Wind face |
