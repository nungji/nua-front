# 마트 상품 아이콘

마트 60단어의 상품 아이콘. 파일 이름은 단어 그대로다(예: `우유.png`).

대부분은 Microsoft Fluent Emoji 3D (https://github.com/microsoft/fluentui-emoji, MIT 라이선스)이다.
딱 맞는 이모지가 없는 아래 19개 단어는 피그마 '글자 마트 · 상품 컴포넌트 (60개)'의 아이콘을 쓴다.

두부, 자두, 요거트, 김치, 치마, 세제, 베개, 기저귀, 치약, 수건,
스피커, 다리미, 드라이기, 밥솥, 리모컨, 선풍기, 냉장고, 세탁기, 청소기
