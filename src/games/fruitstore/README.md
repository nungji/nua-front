# 조개 상점 — 세로 화면

Figma `design images → 조개가게`의 390×844 시안을 기준으로 구현한다.
디자인: https://www.figma.com/design/BYbdINz6CV7nB5o1HIGy21/nua?node-id=348-2251

원본 시안은 합쳐진 이미지 5장이다. 사용자의 승인에 따라 배경·상어 점원·손님·로고를 개별 이미지로 재제작하고, 조개·진열대·바구니·계산대·버튼을 SVG/네이티브 컴포넌트로 구성했다. 원본 화면 이미지를 게임 배경으로 덮어 놓지 않으며, 모든 수량과 조작은 실제 상태에 연결된다. 제작 출처와 프롬프트는 `src/assets/shellstore/README.md`에 기록한다.

- 홈 캐러셀의 **조개 상점** → 시작 화면 → 손님 주문 → 진열대 → 계산대 → 수량 비교 → 보상 → 정산.
- 기존 링크 호환을 위해 `/games/fruitstore`와 내부 ID를 유지한다.
- `?screen=1`부터 `26`까지 기존 주문 흐름의 각 상태를 세로 배치로 미리 볼 수 있다. 원본 시안에 없는 성공·부족·정산 화면은 동일한 스타일로 확장했다.
- `portraitLayout.ts`: 390×844 좌표, 진열대 슬롯, 바구니 영역, 안전 영역 안의 비율 유지.
- `PortraitArt.tsx`: 재제작한 이미지와 SVG. 다른 게임의 바다 테마는 변경하지 않는다.
- `Scene.tsx`: 시작 화면·진열대·계산대·수량 비교·보상 및 드래그앤드롭 조작.
- `game.ts`: 순수 reducer. 손님 4명, 주문당 조개 5개, 보상 동전 3개, 최종 12개.

시안과 같은 9개 묶음 `[2, 3, 4, 6, 7, 1, 2, 3, 4]`을 제공한다. 조개 아래에는 숫자를 표시하지 않는다. 묶음을 모래 바닥으로 끌면 바닥 작업 공간에 놓인다. 진열대에서 바구니로 직접 넣을 수 없다.

바닥에는 여섯 자리가 있다. 다른 묶음 위로 드래그하면 두 묶음이 합쳐진다. 클릭으로는 조개를 이동하거나 합치지 않는다. 바닥 묶음을 선택하면 가위 버튼으로 한 개를 분리할 수 있고, 분리된 조개도 독립된 묶음으로 드래그할 수 있다. 바닥 묶음을 바구니로 끌어 담거나 진열대로 끌어 되돌린다. 바구니의 내용물을 바닥으로 끌면 다시 꺼내 조합할 수 있다. 바닥이 가득 차면 기존 묶음 위로 놓아 합칠 수 있다. 빈 공간이 없으면 하나 떼기는 비활성화한다.

진열대·바닥·바구니 전체의 32개 재고가 보존된다. 바닥/바구니 밖 드롭과 원위치로 돌아온 드래그는 취소된다. 바닥에만 조개가 있으면 계산대로 갈 수 없다. 주문 비교 후 돌아와도 바닥 작업은 유지되고, 다음 손님이나 재시작 때 초기화된다. 수량이 틀려도 벌점 없이 수정한다.

주문표를 누르면 모달로 주문을 다시 확인한다. 앱이 배경으로 가거나 모달이 열리면 자동 장면 전환을 멈춘다. 시간 제한이나 시간 초과 벌점은 추가하지 않았다. 시안의 드래그 중 타이머 자리는 실제 드래그 안내로 대신한다. 새로 시작하면 주문·재고·보상이 초기화된다.

세로 화면을 기본으로 배치하며 가로 창에서도 같은 비율로 축소 표시한다. 앱 전체의 orientation 설정은 기존 `default`를 유지해 다른 게임의 회전을 막지 않는다. 장면 전환은 `useStageRouter`를 사용한다. 새 런타임 의존성은 없다.

검증:

```sh
npm run typecheck
node --test src/games/fruitstore/game.test.mjs
npm exec expo export -- --platform ios --platform web
```

브라우저: Expo 웹 서버 실행 후 Playwright를 사용할 수 있는 환경에서 `node scripts/fruitstore-browser-test.cjs`. `BASE_URL` 기본값은 `http://localhost:8082`, `CHROME_PATH`로 브라우저 경로를 지정할 수 있다. 테스트는 홈 진입, 바닥 배치/합치기/나누기/담기/반환, 모달 포커스, 클릭 이동 방지, 초과·부족 수정, 4명 정산, 재시작 및 5가지 창 크기를 검증한다. 실제 iOS 시뮬레이터/기기 검증은 별도로 필요하다.
